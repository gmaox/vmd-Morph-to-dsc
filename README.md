# vmd-Morph-to-dsc
运行vmd-Morph-to-dsc.py，把vmd文件丢进去，就可以得到一个dsc.txt<p>
（releases中有可以直接运行的exe版本）<p>
你可以把txt中的文字丢到<a href="https://nastys.github.io/dsceditor/">dsc editor</a>进一步处理
<p>并不是所有表情都能转换，有些表情diva没有，并且部分表情幅度也会有差异。
<p>在字典编辑页面，有许多null，这代表该位置还没有对应表情但是diva中有该表情，可尝试将日文表情填入替代。
<p>视频关联：<a href="https://b23.tv/5Cb1ala">将MMD表情移植到Project Diva【歌姬计划】-bilibili</a>
<p>适用于30fps的vmd文件
